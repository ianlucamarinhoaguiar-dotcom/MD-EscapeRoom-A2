# MD-EscapeRoom-A2
Este trabalho propõe a aplicação prática da Teoria dos Grafos no design espacial e na análise de segurança de um jogo de Escape Room. O mapa do jogo é modelado como um grafo simples e conexo 𝐺 = (𝑉 , 𝐸), no qual os vértices 𝑉 representam as salas (cômodos) e as arestas 𝐸 correspondem às passagens diretas entre elas (portas).
